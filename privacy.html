Privacy Policy

Effective 24 October 2026

ClipForge Studio ("the app") is a desktop application that runs entirely on the user's Mac. There is no ClipForge server, account system, analytics service or telemetry.

Data the app accesses

  • Local media the user imports, plus transcripts, clips and settings the app creates. These are stored on the user's Mac and never sent to the developer.
  • Google user data, only after the user connects a YouTube account: the channel ID and title, the list of the channel's videos, and view, like, comment and retention statistics for videos the app uploaded.
  • OAuth tokens issued by Google, stored in the macOS Keychain on the user's Mac.

How Google user data is used

Google user data is used only to provide features the user requests in the app: uploading clips the user approved to the user's own channel, showing which account is connected, and showing performance statistics for those uploads. It is not used for advertising, is not sold, and is not transferred to any third party. No one other than the user can see it.

ClipForge Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data sent to third parties

The app sends data only to services the user explicitly configures:

  • Google / YouTube APIs, for the features above;
  • Twitch APIs (public data only);
  • optional AI providers the user enables (for example a remote model API). This is off by default, and by default only local models are used.

Video and audio files are sent to YouTube only when the user uploads a clip.

Retention and deletion

All data stays on the user's Mac until the user deletes it in the app or removes the app's data folder. Disconnecting a YouTube account in the app deletes its token from the Keychain. Users can also revoke access at any time at myaccount.google.com/permissions.

Security

Credentials are kept in the macOS Keychain and are never written to logs or plain files.

Children

The app is not directed to children under 13.
