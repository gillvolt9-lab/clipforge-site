ClipForge Studio

A personal macOS app for turning long recordings into short vertical clips.

ClipForge Studio runs on the user's own Mac. It transcribes recordings the user imports, suggests short moments, renders vertical clips using the creator's original audio, and checks their quality. All media processing happens locally.

How it uses Google / YouTube

If the user chooses to connect a YouTube account, ClipForge Studio uses Google OAuth to:

  • upload clips the user has explicitly approved to that user's own channel (youtube.upload);
  • read the connected channel's identity and video list (youtube.readonly);
  • read view and retention statistics for videos it uploaded (yt-analytics.readonly).

Nothing is uploaded without the user's approval. Tokens are stored only in the macOS Keychain on the user's Mac.
